# FormatMaster v1.4.4

## Highlights

- Uses the macOS-recommended onedir `.app` layout for DMG releases.
- Restores a valid ad-hoc signature for unsigned macOS builds after Finder
  file associations are written.
- Embeds the release version in the macOS bundle metadata.

## Downloads

- `FormatMaster-1.4.4-macOS-arm64.dmg` — Apple Silicon Macs.
- `FormatMaster-1.4.4-macOS-x86_64.dmg` — Intel Macs.
- `FormatMaster-1.4.4-windows-x64-portable.zip` — Windows 10/11 x64.
- `SHA256SUMS.txt` — SHA256 checksums for all assets.

## macOS first launch

Unsigned builds may show a Gatekeeper warning. In Finder, right-click
**FormatMaster** and choose **Open** once. Developer ID signing and
notarization can be enabled with the repository secrets documented in
`CONTRIBUTING.md`.
