# FormatMaster v1.5.0-beta.2

This prerelease publishes test packages for the v1.5 interface and packaging
changes. Back up important source files and settings before testing.

## Highlights

- The home page now keeps the recent-task list to a fixed number of rows and a
  stable height.
- Runtime status is always visible without a collapse/expand control and uses a
  fixed, complete final row.
- Saved presets now have clearer entry points and guidance for reusing common
  conversion settings.
- Release packages include SPDX dependency manifests and SHA-256 checksums.

## Important unsigned-package notice

The macOS DMGs and Windows portable ZIP in this prerelease are **unsigned test
builds** because release signing credentials are not configured. Their filenames
end in `-unsigned`. macOS Gatekeeper or Windows SmartScreen may display a warning.
Use these packages only for testing, download them only from this repository, and
do not redistribute them as production builds. Stable releases remain blocked
unless the required platform signing and notarization checks pass.

## Verify downloads

Compare every downloaded file with `SHA256SUMS.txt` in this Release. The file
contains the SHA-256 digest for each package and platform-specific SPDX JSON file.
