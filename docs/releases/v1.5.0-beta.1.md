# FormatMaster v1.5.0-beta.1

This is a public prerelease for validating the hardened packaging and update
pipeline before v1.5.0 stable. Back up important source files and settings before
testing.

## Highlights

- Hardened LAN transfer authentication, path handling, and resource limits.
- Added reproducible Python dependency locks and immutable, SHA-256-verified
  FFmpeg, FFprobe, and yt-dlp build inputs.
- Added packaged-executable self-tests, SPDX SBOMs, and complete release checksums.
- Public macOS builds now require Developer ID signing and Apple notarization.
- Windows builds now require a timestamped Authenticode signature.
- PDF passwords are retained only for the current session. Any legacy plaintext
  password-history preference is cleared when the PDF panel is opened.
- Added privacy, security-reporting, dependency-update, and contribution policies.
- Adopted AGPL-3.0-or-later for this release while preserving the historical
  MIT attribution in `NOTICE`.

## Compatibility and known limitations

- Packages are provided for Windows 10/11 x64, Apple Silicon macOS, and Intel macOS.
- macOS updates are installed manually from GitHub Releases; Windows portable
  updates support verified download and rollback.
- Some Office, ebook, and specialized document conversions still require external
  software such as Microsoft Office, LibreOffice, or Calibre.
- This prerelease should not replace a working installation without a backup.

## Verify downloads

Download only from this repository's GitHub Releases. Every public asset is listed
in `SHA256SUMS.txt`; verify its SHA-256 digest before running it. Platform-specific
SPDX JSON files describe the packaged Python dependencies.
