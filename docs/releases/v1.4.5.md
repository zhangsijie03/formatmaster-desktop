# FormatMaster v1.4.5

## Highlights

- Keeps the macOS onedir `.app` DMG packaging and valid unsigned-build
  ad-hoc signature from v1.4.4.
- Uses a Windows onedir directory inside the portable ZIP for more reliable
  CI builds with QtWebEngine, OCR, and PyMuPDF.

## Downloads

- `FormatMaster-1.4.5-macOS-arm64.dmg` — Apple Silicon Macs.
- `FormatMaster-1.4.5-macOS-x86_64.dmg` — Intel Macs.
- `FormatMaster-1.4.5-windows-x64-portable.zip` — Windows 10/11 x64.
- `SHA256SUMS.txt` — SHA256 checksums for all assets.

## Windows first launch

Extract the ZIP, open the `格式大师` folder, and run `格式大师.exe`.

## macOS first launch

Unsigned builds may show a Gatekeeper warning. In Finder, right-click
**FormatMaster** and choose **Open** once. Developer ID signing and
notarization can be enabled with the repository secrets documented in
`CONTRIBUTING.md`.
