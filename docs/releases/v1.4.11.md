# FormatMaster v1.4.11

## Highlights

- Includes the responsive dashboard, refined conversion panels, consistent
  action states, and interaction improvements introduced in v1.4.9.
- Keeps text watermarking independent of FFmpeg's optional `drawtext` filter
  and reliably discovers yt-dlp from the active Python environment.
- Preserves searchable Chinese text in built-in Office-to-PDF output on
  minimal Linux systems through a bundled CJK CID font fallback.
- Fixes Windows locale handling, platform-specific subprocess flags, macOS
  LibreOffice/Calibre detection, and LaunchAgent compatibility.
- Aligns cross-platform regression tests with the production runtime contract
  and validates the complete source suite on Ubuntu, Windows, and macOS.

## macOS first launch

The macOS builds use an ad-hoc signature when Apple signing credentials are
not configured and may not be notarized. Drag **FormatMaster** into
**Applications** and try to open it once. If Gatekeeper blocks it, open
**System Settings → Privacy & Security** and choose **Open Anyway** for
FormatMaster. Do not disable Gatekeeper globally.
