# FormatMaster v1.4.9

## Highlights

- Refines the dashboard and conversion panels with clearer hierarchy,
  responsive layouts, improved empty states, and consistent action placement.
- Makes file removal and clearing follow the current file/selection state and
  adds regression coverage for the new interaction behavior.
- Finds the yt-dlp console script from the active Python environment even when
  that environment has not been added to `PATH`.
- Replaces the optional FFmpeg `drawtext` dependency with a Pillow-rendered
  transparent text layer and FFmpeg overlay composition for reliable text
  watermarks across supported builds.
- Revalidates all navigation entries, conversion contracts, LAN transfer,
  packaged media tools, the packaged quick-convert path, code signing, and the
  macOS DMG layout from a clean Python 3.11 environment.

## macOS first launch

The macOS builds use an ad-hoc signature when Apple signing credentials are
not configured and may not be notarized. Drag **FormatMaster** into
**Applications** and try to open it once. If Gatekeeper blocks it, open
**System Settings → Privacy & Security** and choose **Open Anyway** for
FormatMaster. Do not disable Gatekeeper globally.
