# FormatMaster v1.0.0

FormatMaster 1.0.0 is the first production release of the all-in-one desktop
format conversion toolkit. Back up important source files and application
settings before adopting a new conversion workflow.

## Highlights

- Convert common video, audio, image, document, ebook, archive, and data formats
  from one desktop application.
- Provide focused tools for PDF processing, QR codes, ID photos, M3U8 downloads,
  media downloads, and authenticated LAN file transfer.
- Harden path handling, authentication, resource limits, private-key storage,
  and sensitive PDF preference cleanup.
- Ship reproducible Python dependency locks and SHA-256-verified FFmpeg,
  FFprobe, and yt-dlp inputs.
- Include packaged-executable self-tests, SPDX SBOMs, release checksums, and
  build provenance attestations.
- Support Windows 10/11 x64, Apple Silicon macOS, and Intel macOS.

## Compatibility and known limitations

- Some Office, ebook, and specialized document conversions require external
  software such as Microsoft Office, LibreOffice, or Calibre.
- macOS updates are installed manually from GitHub Releases. Windows portable
  updates support verified download and rollback.
- Conversion results depend on the capabilities of the installed codecs and
  external tools; keep backups of irreplaceable source files.

## Verify downloads

Download packages only from this repository's GitHub Releases page. Every
published asset is covered by `SHA256SUMS.txt`; verify its SHA-256 digest before
running it. Platform-specific SPDX JSON files describe packaged dependencies.
