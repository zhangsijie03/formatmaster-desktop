# FormatMaster v1.4.10

## Highlights

- Includes the v1.4.9 dashboard and conversion-panel redesign with clearer
  hierarchy, responsive layouts, improved empty states, and consistent actions.
- Keeps text watermarks independent of FFmpeg's optional `drawtext` filter by
  composing a Pillow-rendered transparent layer through FFmpeg overlay.
- Finds yt-dlp beside the active Python executable even when the environment's
  script directory is absent from `PATH`.
- Preserves searchable Chinese text in the built-in Office-to-PDF fallback on
  minimal Linux systems by using ReportLab's bundled CJK CID font.
- Fixes runtime platform detection for Windows subprocess flags, macOS
  LibreOffice/Calibre fallbacks, LaunchAgent compatibility, and Windows locale
  handling in the ID-card parser.
- Unifies the public task-running state as `processing` and revalidates the
  source and packaged conversion paths across supported platforms.

## macOS first launch

The macOS builds use an ad-hoc signature when Apple signing credentials are
not configured and may not be notarized. Drag **FormatMaster** into
**Applications** and try to open it once. If Gatekeeper blocks it, open
**System Settings → Privacy & Security** and choose **Open Anyway** for
FormatMaster. Do not disable Gatekeeper globally.
