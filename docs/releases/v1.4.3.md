- Fixed macOS release packaging for static FFmpeg and FFprobe.
- Fixed Windows PyInstaller preflight and PyMuPDF package collection.
- Rebuilt the cross-platform release pipeline for macOS and Windows.

- `SHA256SUMS.txt` — SHA256 checksums for all assets.

## macOS first launch

If the release was built without Apple Developer ID credentials, macOS may
show a Gatekeeper warning. In Finder, right-click **FormatMaster** and choose
**Open** once. Signing and notarization can be enabled with the repository
secrets documented in `CONTRIBUTING.md`.
