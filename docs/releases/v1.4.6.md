# FormatMaster v1.4.6

## Highlights

- Keeps the macOS onedir `.app` DMG packaging and valid unsigned-build
  ad-hoc signature.
- Uses a Windows onedir directory inside the portable ZIP.
- Publishes Windows dependency preflight and build logs as diagnostics when
  the runner fails before producing the portable ZIP.
