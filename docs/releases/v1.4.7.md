# FormatMaster v1.4.7

## Highlights

- Fixes Windows CI builds that failed before PyInstaller when a Chinese path
  or missing-resource warning was written through the runner's cp1252 stream.
- Keeps the macOS onedir `.app` DMG and Windows onedir portable ZIP pipeline.

## Downloads

- `FormatMaster-1.4.7-macOS-arm64.dmg` — Apple Silicon Macs.
- `FormatMaster-1.4.7-macOS-x86_64.dmg` — Intel Macs.
- `FormatMaster-1.4.7-windows-x64-portable.zip` — Windows 10/11 x64.
- `SHA256SUMS.txt` — SHA256 checksums for all release assets.

## macOS first launch

The macOS builds use an ad-hoc signature and are not notarized. Drag
**FormatMaster** into **Applications** and try to open it once. If Gatekeeper
blocks it, open **System Settings → Privacy & Security** and choose
**Open Anyway** for FormatMaster. Do not disable Gatekeeper globally.
