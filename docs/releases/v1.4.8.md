# FormatMaster v1.4.8

## Highlights

- Restores the local FastAPI REST service with health, video-conversion, and
  document-conversion endpoints, including structured errors and output-name
  collision protection.
- Aligns the task center with the acceptance contract: 500 ms FIFO dispatch,
  `waiting` → `processing` state flow, clear-completed and cancel controls,
  plus a 50-line color-coded log with clear and double-click copy actions.
- Preserves source aspect ratio for resolution presets instead of stretching
  non-standard video dimensions.
- Cleans up macOS font fallback and invalid Qt stylesheets, adds the native
  `.icns` application icon, and validates the arm64 application and DMG flow.
- Adds executable acceptance-contract coverage and verifies real media,
  document, packaged CLI, packaged API, DMG, and code-signing paths.

## macOS first launch

The macOS builds use an ad-hoc signature when Apple signing credentials are
not configured and may not be notarized. Drag **FormatMaster** into
**Applications** and try to open it once. If Gatekeeper blocks it, open
**System Settings → Privacy & Security** and choose **Open Anyway** for
FormatMaster. Do not disable Gatekeeper globally.
