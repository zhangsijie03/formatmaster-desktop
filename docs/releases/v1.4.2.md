# FormatMaster v1.4.2

## Highlights

- Added automated GitHub Actions releases for macOS and Windows.
- Added native Apple Silicon and Intel macOS DMG assets.
- Added a Windows x64 portable ZIP asset.
- Bundled static FFmpeg, FFprobe, and yt-dlp in release builds.
- Added SHA256 checksums for every downloadable artifact.
- Added a standard macOS DMG layout with an `Applications` shortcut.
- Added optional Developer ID signing, notarization, and ticket stapling.

## Downloads

- `FormatMaster-1.4.2-macOS-arm64.dmg` — Apple Silicon Macs.
- `FormatMaster-1.4.2-macOS-x86_64.dmg` — Intel Macs.
- `FormatMaster-1.4.2-windows-x64-portable.zip` — Windows 10/11 x64.
- `SHA256SUMS.txt` — SHA256 checksums for all assets.

## macOS first launch

If the release was built without Apple Developer ID credentials, macOS may
show a Gatekeeper warning. In Finder, right-click **FormatMaster** and choose
**Open** once. The release workflow supports signing and notarization when the
repository secrets described in `CONTRIBUTING.md` are configured.

## Known limitations

- This release does not provide a Linux desktop binary; Linux remains supported
  from source.
- Document conversions that depend on Microsoft Office or Calibre still need
  those applications installed separately on the target machine.
- Online video download features depend on the target website and yt-dlp's
  current extractor support.
